<h3 align="left">🚀 What I'm working on</h3>

#### 🌾 SailoPortal — Agricultural management system
A web platform for the agricultural sector, built on Xiara's multi-tenant **C#/.NET** framework with a **JavaScript** frontend and **SQL Server** backend.
- Full-stack feature development: backend services in C#, dynamic forms and UI in JavaScript, and SQL views and queries
- Multi-tenant data model — every query and view scoped per organization
- Deployments across pre-production and production environments using Git

#### 🏦 Nexar — Loan origination platform
An end-to-end credit origination system for mutual / cooperative lending organizations.
- **Loan application flow**: applicant onboarding, loan plan configuration and comparison, and credit evaluation
- **Banking validations**: CBU checksum validation (official BCRA algorithm) and CBU/CUIT ownership verification through external banking APIs
- **Digital signature**: generation of e-signature links through third-party API integrations
- **Document workflows**: proof-of-income upload and verification, with camera capture support on mobile
- **Data layer**: SQL Server views and C# services with LINQ, tuned for multi-tenant correctness
- Exploring **AI agents** (Claude Code + MCP connected to SQL Server) as a development assistant for the platform
